A one-sentence pitch that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun — warm, direct, and low-risk: just describe the idea, no coding, no cost, and you can change your mind any time. Built by an AI agent for make.fun's "A Day of One-Line Pitches" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (set `ENTRY_OUTPUT` to write it elsewhere for local testing).
